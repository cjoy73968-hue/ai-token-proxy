# 模型选择指南

## 概述

本系统支持多个 AI 模型，用户可以根据需求选择不同的模型进行对话。不同模型有不同的特点和配额消耗比例。

## 支持的模型

| 模型 ID | 名称 | 特点 | 配额消耗比例 |
|--------|------|------|-------------|
| MiniMax-M2.7 | MiniMax M2.7 | 高速稳定，适合日常对话 | 1.0x |
| deepseek-chat | DeepSeek Chat | 高性价比，擅长逻辑推理 | 1.0x |
| glm-4 | 智谱 GLM-4 | 强中文理解，内容创作 | 1.2x |
| moonshot-v1-8k | Kimi | 长上下文，适合长文分析 | 1.5x |
| gpt-4 | GPT-4 | 最强推理能力，适合复杂任务 | 3.0x |

## 如何选择模型

### 1. 打开用户中心

在小程序中点击右下角「我的」，进入用户中心页面。

### 2. 选择模型

在用户中心页面，点击「选择 AI 模型」下拉框，可以看到您套餐包含的所有模型。

### 3. 切换模型

选择一个模型后，系统会显示该模型的消耗比例。切换后，您发送的消息将使用选定的模型处理。

## 配额消耗说明

配额消耗计算公式：

```
实际消耗 = 请求 Token 数 × 模型比例
```

### 示例

假设用户发送一条消息，消耗 1000 Tokens：

| 选择的模型 | 比例 | 实际消耗 |
|-----------|------|----------|
| DeepSeek | 1.0x | 1000 |
| GLM-4 | 1.2x | 1200 |
| GPT-4 | 3.0x | 3000 |

**注意**：GPT-4 的消耗是 DeepSeek 的 3 倍，使用时请注意配额余额。

## 查看使用统计

在用户中心页面下方可以查看「模型使用统计」，显示您使用各模型的次数。

## 常见问题

### Q: 为什么我看不到某些模型？

只有当您的套餐包含该模型时才能使用。基础版仅包含 MiniMax-M2.7，如需更多模型请升级套餐。

### Q: 切换模型后配额会变化吗？

切换模型不会影响配额余额，但不同模型的消耗比例不同会影响配额的使用速度。

### Q: 默认使用哪个模型？

新用户默认使用套餐的默认模型（通常是 MiniMax-M2.7）。您可以在用户中心随时切换。

### Q: 如何知道还剩多少配额？

在用户中心页面顶部显示您的当前余额。当余额低于 100 时，系统会显示预警提示。

## 配额预警

当服务配额低于 100 次时，系统会显示「服务配额不足」的预警提示。请及时续费以保证服务正常使用。

## 续费说明

如需续费，请返回首页选择相应套餐进行购买。续费后配额将自动恢复。
