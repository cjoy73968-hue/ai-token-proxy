# 微信支付商户号配置指南

## 概述

本系统使用微信支付 V3 接口实现包月套餐的支付功能。配置微信支付商户号后，用户可以通过微信支付购买服务套餐。

## 配置步骤

### 1. 获取微信支付商户号

1. 前往 [微信支付商户平台](https://pay.weixin.qq.com/) 申请商户号
2. 完成企业资质认证和对公账户验证
3. 获取商户号（MCH_ID）

### 2. 获取 APIv3 密钥

1. 登录微信支付商户平台
2. 进入「账户中心」→「API安全」
3. 设置 APIv3 密钥（32位字符串）
4. 保存密钥，请勿泄露

### 3. 配置证书

微信支付 V3 接口需要使用证书进行签名验证：

1. 在商户平台「账户中心」→「API安全」下载证书
2. 将证书文件放置在安全位置
3. 配置证书路径（可选）

### 4. 配置回调地址

1. 在商户平台「交易设置」→「Native反馈消息」
2. 配置回调地址：`https://你的域名/admin/pay-notify`
3. 确保地址可公网访问，微信支付会向此地址发送回调通知

### 5. 更新代码配置

在 `agent-backend/main.py` 中更新以下配置：

```python
# 微信支付商户号配置
MCH_ID = "你的商户号"  # 例如: 1234567890
API_V3_KEY = "你的APIv3密钥"  # 32位字符串
NOTIFY_URL = "https://你的域名/admin/pay-notify"  # 回调地址
```

### 6. 配置防火墙

确保服务器防火墙/安全组允许：
- 443 端口（HTTPS）
- 微信支付回调地址可访问

## 注意事项

1. **安全保管**：APIv3 密钥和证书文件必须安全保管，切勿提交到代码仓库
2. **回调验证**：生产环境建议实现完整的微信支付 V3 签名验证
3. **测试环境**：开发测试时可使用沙箱环境

## 回调接口说明

支付成功后，微信支付会向配置的回调地址发送通知。本系统的回调接口会：
1. 验证回调签名
2. 更新订单状态
3. 自动为用户充值服务配额

## 故障排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 回调接收不到 | 回调地址不可访问 | 检查防火墙和HTTPS配置 |
| 签名验证失败 | APIv3密钥不匹配 | 确认密钥与商户平台一致 |
| 订单状态未更新 | 回调处理异常 | 检查日志，联系管理员 |
