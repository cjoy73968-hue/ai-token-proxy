# 三、流量消耗统计方案（2种任选）
## 方案1：简易计数统计（新手首选，不用改代码）
### 原理
1. 你后台**记录每个客户每日调用次数**
2. 预设平均值：**1次对话≈500Token**
3. 直接按次数扣减表格内剩余流量

**优点**：零技术、随手记账、手机就能操作
**适合**：日单量50人以内小体量

## 方案2：代码内嵌精准统计（精准扣量，全自动）
修改之前`main.py`，增加**密钥绑定流量+自动扣量+余额判定**
### 1. 配置客户密钥流量字典
```python
# 客户密钥-剩余流量 字典（单位：万Token）
USER_TOKEN_BALANCE = {
    "tk202605181001": 1150,
    "tk202605181002": 6000,
    "tk202605181003": 23000
}

# 单次对话平均消耗Token（可自行调整）
AVG_USE = 0.05
```

### 2. 鉴权前新增余额判断
```python
# 校验密钥+判断余额
if user_key not in ALLOW_USER_KEYS:
    raise HTTPException(status_code=401, detail="无效密钥")

# 余额不足直接拒绝访问
if USER_TOKEN_BALANCE.get(user_key, 0) <= 0:
    raise HTTPException(status_code=403, detail="流量已耗尽，请续费")

# 自动扣减流量
USER_TOKEN_BALANCE[user_key] -= AVG_USE
```

### 3. 效果
- 余额充足：正常转发使用
- 余额≤0：**直接禁止调用，自动回收使用权**
- 无需手动关停密钥，全自动管控
