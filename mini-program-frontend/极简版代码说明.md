## 二、FastAPI中转后端完整代码 `main.py`
**核心规则：不存对话、不存日志、纯转发、无数据留存**
```python
from fastapi import FastAPI, Request, HTTPException
import httpx
import time

app = FastAPI(title="Token中转代理")

# ========== 自行修改配置 ==========
# 上游官方API密钥
UPSTREAM_API_KEY = "sk-你的上游正规Key"
# 上游接口地址（国内模型优先，禁止境外GPT跨境）
UPSTREAM_API_URL = "https://api.deepseek.com/v1/chat/completions"
# 下游用户可用密钥（自己批量新增）
ALLOW_USER_KEYS = {
    "tk_20260518001",
    "tk_20260518002",
    "tk_20260518003"
}
# 单IP限流次数
LIMIT_COUNT = 60
ip_record = {}
# =================================

# 限流中间件
@app.middleware("http")
async def limit_middleware(request: Request, call_next):
    client_ip = request.client.host
    now = int(time.time())
    if client_ip not in ip_record or now - ip_record[client_ip]["time"] > 60:
        ip_record[client_ip] = {"count": 1, "time": now}
    else:
        ip_record[client_ip]["count"] += 1
        if ip_record[client_ip]["count"] > LIMIT_COUNT:
            raise HTTPException(status_code=429, detail="请求过于频繁，请稍后再试")
    response = await call_next(request)
    return response

# 通用转发接口（兼容OpenAI格式）
@app.post("/v1/chat/completions")
async def chat_proxy(request: Request):
    # 校验下游密钥
    auth = request.headers.get("Authorization", "")
    if not auth.startswith("Bearer "):
        raise HTTPException(status_code=401, detail="密钥错误")
    user_key = auth.replace("Bearer ","")
    if user_key not in ALLOW_USER_KEYS:
        raise HTTPException(status_code=401, detail="无效代理密钥")

    # 获取请求体（不落地存储）
    raw_data = await request.json()

    # 转发上游
    headers = {
        "Authorization": f"Bearer {UPSTREAM_API_KEY}",
        "Content-Type": "application/json"
    }
    async with httpx.AsyncClient(timeout=120) as client:
        res = await client.post(UPSTREAM_API_URL, json=raw_data, headers=headers)
    
    # 直接原路返回，不保存任何内容
    return res.json()

# 健康检测
@app.get("/")
async def health():
    return {"status":"running","note":"纯中转无数据存储"}
```

## 三、创建虚拟环境+启动脚本
### 1. 安装依赖
```bash
python3 -m venv venv
source venv/bin/activate
pip install fastapi uvicorn httpx
```

### 2. 后台常驻启动 `run.sh`
```bash
#!/bin/bash
source /home/tokenproxy/venv/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 2
```
授权运行：
```bash
chmod +x run.sh
```

### 3. 系统守护进程（开机自启）
创建 `tokenproxy.service`
```ini
[Unit]
Description=Token Proxy Service
After=network.target

[Service]
User=root
WorkingDirectory=/home/tokenproxy
ExecStart=/home/tokenproxy/run.sh
Restart=always

[Install]
WantedBy=multi-user.target
```
部署命令：
```bash
mv tokenproxy.service /etc/systemd/system/
systemctl daemon-reload
systemctl start tokenproxy
systemctl enable tokenproxy
```

## 四、Nginx反向代理+HTTPS配置
### 1. Nginx站点配置 `/etc/nginx/sites-available/proxy.conf`
```nginx
server {
    listen 80;
    server_name 你的域名.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name 你的域名.com;

    ssl_certificate /etc/letsencrypt/live/你的域名.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/你的域名.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_connect_timeout 120s;
        proxy_send_timeout 120s;
        proxy_read_timeout 120s;
    }
}
```
启用站点：
```bash
ln -s /etc/nginx/sites-available/proxy.conf /etc/nginx/sites-enabled/
nginx -t
systemctl restart nginx
```

### 2. 免费SSL证书申请
```bash
apt install certbot python3-certbot-nginx -y
certbot --nginx -d 你的域名.com
```

## 五、核心风控&安全强制清单（必做）
1. **彻底关闭日志**
   修改uvicorn启动参数加：`--access-log-fmt ""` 禁止记录对话内容
2. **禁止存储任何数据**
   不搭建数据库、不保存用户提问、不缓存上下文
3. **上游只选用国内正规大模型**
   DeepSeek、智谱、阿里百炼、腾讯混元，**严禁对接境外OpenAI做国内流量**
4. **密钥管理**
   上游主密钥7天更换一次，下游用户密钥单独分配，一人一密
5. **防火墙封禁**
   只放行80、443端口，关闭多余端口
6. **绝不做**
   多级分销、资金池、预存大额货款、售卖黑卡密钥、篡改模型内容

3. 上游报错：核对上游Key与接口地址
